## p.7 GET / POST 역할

### GET

- 게시물(이미지) 목록 획득
- 응답 형식: JSON Array
- 각 게시물에 이미지 URL 포함

### POST

- 게시물(이미지 포함) 업로드
- 전송 형식: Multipart
  - Text
  - Image

```java
private class CloadImage extends AsyncTask<String, Integer, List<Bitmap>> {
    @Override
    protected List<Bitmap> doInBackground(String... urls) {
        List<Bitmap> bitmapList = new ArrayList<>();

        try {
            String apiUrl = urls[0];
            String token = "bf46b8f9337d1d27b4ef2511514c798be1a954b8";
            URL urlAPI = new URL(apiUrl);
            HttpURLConnection conn = (HttpURLConnection) urlAPI.openConnection();
            conn.setRequestProperty("Authorization", "Token " + token);
            conn.setRequestMethod("GET");
            conn.setConnectTimeout(3000);
            conn.setReadTimeout(3000);

            int responseCode = conn.getResponseCode();
            if (responseCode == HttpURLConnection.HTTP_OK) {
                InputStream is = conn.getInputStream();
                BufferedReader reader = new BufferedReader(new InputStreamReader(is));
                StringBuilder result = new StringBuilder();
                String line;
                while ((line = reader.readLine()) != null) {
                    result.append(line);
                }
                is.close();
```

## p.22 CloadImage 클래스 - JSON 파싱 및 이미지 다운로드

```java
                String strJson = result.toString();
                JSONArray aryJson = new JSONArray(strJson);

                // 배열 내 모든 이미지 다운로드
                for (int i = 0; i < aryJson.length(); i++) {
                    post_json = (JSONObject) aryJson.get(i);
                    imageUrl = post_json.getString("image");

                    if (!imageUrl.equals("")) {
                        URL myImageUrl = new URL(imageUrl);
                        conn = (HttpURLConnection) myImageUrl.openConnection();

                        Bitmap imageBitmap = BitmapFactory.decodeStream(imgStream);
                        bitmapList.add(imageBitmap); // 이미지 리스트에 추가

                    }
                }
            }
        } catch (IOException | JSONException e) {
            e.printStackTrace();
        }

        return bitmapList;
    }
```

3. `image` 필드의 URL을 읽음

# 전체 구현 흐름 요약

```text
[Django Server]
    Post 모델/Serializer
        ↓
    BlogImages(ModelViewSet)
        ↓
    /api_root/Post/
        ↓ GET: JSON Array (image URL 포함)
        ↓ POST: Multipart(Text + Image)

[Android Client]
    AndroidManifest 권한/Network Security
        ↓
    MainActivity
        ↓ onClickDownload()
    CloadImage(AsyncTask)
        ↓ GET + Token 인증
    JSON Array 파싱
        ↓
    각 image URL 다운로드 → Bitmap List
        ↓
    ImageAdapter + RecyclerView
        ↓
    이미지 목록 표시
```
